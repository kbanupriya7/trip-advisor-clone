# Tripadvisor Clone Website

## About the Project

This is my third frontend development project, inspired by the Tripadvisor travel website. I am building this project using HTML and CSS as part of my Full Stack Web Development learning journey.

The goal of this project is to recreate the look and layout of a travel website where users can explore destinations, discover places to visit, and find travel-related information.

## Features

- Navigation bar
- Travel search section
- Travel destination showcase
- Hotel and restaurant sections
- Travel inspiration and discovery sections
- Image-based layouts
- Styled buttons, links, and content sections

## Technologies Used

- HTML5
- CSS3

## What I Am Learning

- Structuring webpages using HTML
- Styling layouts using CSS
- Working with images and transition
- Creating navigation bars and content sections
- Practising spacing, alignment, and positioning
- Improving frontend development skills
- Responsive layout

## Project Purpose

This project is created for educational and practice purposes to improve my HTML and CSS skills.

**Note:** This is an independent practice project inspired by Tripadvisor. It is not an official Tripadvisor website. Search, booking, and other interactive features are not functional unless implemented separately.

## Future Improvements

- Make the website responsive for mobile devices.
- Add interactive features using JavaScript.
- Improve the layout and visual design.
- Explore backend integration in future projects.
